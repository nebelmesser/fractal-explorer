The map

Each pixel is a complex number p. At the Mandelbrot end, iterate z ← z² + p starting at z = 0. Black points have not escaped within the iteration limit; the blue, cyan, cream, and gold exterior follows the smooth escape time. More iterations resolve slower escapes near the boundary.

From Mandelbrot to Julia

The transition slider t continuously changes both the starting point and the constant: z₀ = t p and c = (1 − t) p + t c_J, then z ← z² + c. At t = 0 this is the Mandelbrot set. At t = 1 it is the filled Julia set for c_J, whose real and imaginary parts are adjustable. Intermediate values are a continuous family of escape-time maps, not a crossfade of two images. The imaginary axis points upward.

Orbits

The trajectory setting is enabled by default and shows a persistent overview of the whole current set, even when the pointer is outside the map. The overview follows the current Mandelbrot–Julia transition, Julia constant, iteration limit, and palette. The horizontal axis has real-number ticks; the vertical ticks are multiples of italic i, with positive imaginary values upward. On hover or tap it displays the selected pixel as a single italic complex number, a + bi, without separate Cartesian-coordinate rows. This value updates immediately; very long deep-zoom decimals are abbreviated with an ellipsis.

The overview always draws the selected orbit. The trajectory is also always drawn directly on the fractal, even when z₀ is outside the viewport, clipping parts outside the screen and keeping the curve out of the overview panel. The selected point and its trajectory persist when the pointer leaves the map and during pan, pinch, wheel zoom, and zoom animations; navigation only reprojects the same trajectory. Moving the mouse over another point or tapping another point selects a new orbit. The curve fades in smoothly and the previous curve stays visible until the next worker result is ready; successive curves crossfade during pointer movement. Independently of the full trajectory, z₀ is marked on the main map whenever it is visible; a callout joins z₀ to the hovered point when both fit on screen. Otherwise the overview provides the context. The cyan-to-violet-to-pink-to-gold curve indicates iteration order; moving dots start after the cursor rests for half a second. In Mandelbrot mode the selected pixel is the parameter p = c and z₀ = 0. During the transition z₀ = t p; in Julia mode z₀ = p. Do not confuse the selected parameter with the initial orbit value. Interiors remain black. Cycle detection is limited to periods up to 256 and the iteration budget; an unknown cycle does not prove escape or nonperiodicity.

Navigation

Click or double-tap to zoom, drag to pan, and use the wheel, pinch, or +/− buttons. Right-click and reset view go back. The settings control the transition, Julia constant, and iteration limit. Deep zoom uses an exact camera center and a high-precision reference orbit computed in a worker. The GPU evaluates nearby orbits using scaled perturbations and paired f32 mantissas; unstable pixels get another reference or a high-precision CPU repair. The minimum view span is 1e-280. The iteration limit still controls visible detail: raise it when slow-escaping regions look black. The cpu=1 URL option computes the entire view in CPU workers without requesting WebGPU.
